# Snake Game 🐍

This is a simple snake game that I made using HTML, CSS, and JavaScript. The interesting part is that I can control the snake by moving my nose in front of the webcam!

## How to Play

* Allow the game to access your webcam.
* Move your nose to control the snake.
* Collect the red food to increase your score.
* Don't let the snake touch the edges.
* Click the Restart Game button to play again.

## Tools Used

* HTML
* CSS
* JavaScript
* p5.js
* ml5.js

## What I Learned

* How to make a simple game using JavaScript.
* How to use p5.js to create a game canvas.
* How to use nose tracking to control a game.
* How to use Git and GitHub to upload my project.

## How to Run

1. Download the project.
2. Open the `index.html` file in a browser.
3. Allow webcam access and start playing!

**Note:** An internet connection is needed to load the libraries.
